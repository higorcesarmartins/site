Pesquisa · Conceitos fundamentais

O que é software?

Software é o conjunto de instruções e dados que orienta um computador a realizar tarefas. Diferente do hardware, que corresponde às partes físicas do equipamento, o software não pode ser tocado. O sistema operacional, os aplicativos e os jogos são exemplos de software.

Principais categorias

Software de sistema

Controla o funcionamento do dispositivo e oferece uma base para os outros programas. Windows, macOS, Linux, Android e iOS são exemplos de sistemas operacionais. Drivers e ferramentas de manutenção também fazem parte dessa categoria.

Software aplicativo

Ajuda o usuário a realizar atividades específicas. Editores de texto, navegadores de internet, planilhas, programas de desenho e aplicativos de mensagens são exemplos de softwares aplicativos.

Software de programação

Reúne ferramentas usadas para criar, testar e manter outros programas. Editores de código, compiladores e ambientes de desenvolvimento são alguns exemplos.

Como escolher um programa?

A escolha depende da tarefa, do dispositivo e dos requisitos de segurança e compatibilidade. Também é importante verificar a origem do programa, as permissões solicitadas, o custo e as condições de uso. Manter os softwares atualizados ajuda a corrigir falhas e proteger os dados.
